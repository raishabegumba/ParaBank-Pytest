You are an expert software engineer. 

Analyze UI automation test failures using JSON artifacts located in:

reports/html/test_report_*.json

Each JSON file has the following structure:

{
  "test_name": "",
  "test_file": "",
  "status": "passed | failed | skipped | unknown",
  "duration": 0.0,
  "error_message": "",
  "start_time": "",
  "end_time": "",
  "metadata": {
    "markers": [],
    "node_id": ""
  }
}
Objective

Fix failing UI automation test cases by analyzing the JSON failure reports and updating only the relevant test/module code.

Tasks
1. Identify Failed Tests

Scan all JSON files and process only:

status = "failed"

Ignore passed/skipped tests.

2. Extract Failure Details

For each failed test:

Identify:
test_name
test_file
metadata.node_id
failing line from stack trace
assertion or exception message
Read the corresponding Python test file.
Trace related:
Page Object methods
utility/helper methods
fixtures
navigation/login helpers
3. Classify Root Cause

Classify failures into one of these categories:

Login/authentication failure
Locator issue (element changed/not found)
Assertion mismatch
Timing/synchronization issue
Data/setup issue
Framework/Page Object issue
Environment/session issue
Important Failure Pattern

If the error contains:

assert login_result['success'], "Login should be successful"
E assert False

Treat it as a shared login/navigation framework issue.

Investigate:

login helper methods
credential loading
session persistence
redirects/navigation
waits after login
page load synchronization
stale locators after login
unexpected logout/session expiry

Fix the shared root cause instead of patching individual tests.

Fix Requirements

For each failed test:

Explain root cause
Apply minimal targeted fix
Preserve existing framework structure
Reuse existing utilities/helpers
Avoid duplicate code
Improve waits/synchronization where necessary
Prefer robust Playwright/Pytest patterns
Expected Output Format

For each fix provide:

Test Name:
File:
Root Cause:
Fix Applied:
Files Modified:
Recommendation:

Then provide the actual code changes.

Constraints
Do NOT modify passing tests
Do NOT rewrite unrelated modules
Do NOT hardcode sleeps unless unavoidable
Prefer explicit waits over time.sleep()
Keep Page Object Model architecture intact
Keep fixes production-quality and maintainable
Execution Order
Summarize all failed tests
Group similar failures together
Fix shared framework/login issues first
Then fix module-specific failures
Finally identify flaky tests and stabilization improvements
Additional Guidance

When handling Playwright failures:

Use explicit waits
Avoid unstable nth() chains where possible
Reuse locators instead of repeatedly querying DOM
Validate page state before assertions
Prefer .inner_text() over unstable .text_content() where appropriate
